X Context Bridge

最簡單的安裝方式

電腦可直接把上面的藍色按鈕拖到書籤列。手機請不要只複製 GitHub 網址，要把 GITHUB_BOOKMARKLET.txt 裡面整串 javascript: 內容貼到書籤網址。

如果在 X 上沒有反應

X 可能阻擋短版書籤從 GitHub 載入程式。這時改用 完整離線書籤，它不需要再連回 GitHub 載入主程式。

  1. 手機先把任意頁面加入書籤。
  2. 編輯剛才的書籤，名稱改成 X Context Bridge。
  3. 把網址替換成 GITHUB_BOOKMARKLET.txt 的完整內容，不是檔案網址。
  4. 開啟 X 私訊網頁後執行這個書籤。

完整離線書籤很長；有些手機瀏覽器可能會限制書籤網址長度。若手機不能存，先用短版；短版被擋時再回到電腦測完整離線版。
