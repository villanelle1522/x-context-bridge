開啟安裝檔

為什麼不是書籤？X 的 CSP 會阻擋書籤從 GitHub Pages 載入外部程式；完整離線書籤又超過許多手機的長度限制。Userscript 是目前免費且可靠的方式。

操作手勢速查

工具會盡量沿用 X 原本的泡泡、字級與操作位置；電腦與手機的入口稍有不同。

01

開啟總設定

點 X 私訊右側的書籤圖示。若圖示位於畫面邊緣，可用滑鼠或手指上下拖曳。

02

開啟訊息編輯器

電腦：在訊息泡泡按右鍵。手機：點一下訊息泡泡。已顯示譯文時，手機點譯文也能開啟。

03

切換三層內容

手機左右滑；滑鼠按住譯文左右拖；觸控板水平滑動，或按住 Shift 滾動滾輪。

04

只摘錄長訊息的一部分

先反白選取原文片段，再開啟訊息編輯器並進入「整理」；選取內容會成為預設摘錄。

05

鍵盤快捷鍵

Ctrl + Shift + T 顯示／隱藏翻譯； Ctrl + Shift + M 開啟設定。

06

Clean

設定視窗底部的 Clean 會移除翻譯層與工具介面，但保留已儲存的本機資料；重新整理頁面可重新載入 Userscript。

訊息泡泡的三層閱讀

預設先顯示譯文；第二頁是原文，第三頁是逐字／語氣說明。

1完整譯文

Google 初譯、AI 精修或你手動更正後的版本。直接覆蓋在原泡泡上。

2原文

永遠保留 X 原始訊息，需要核對時只要滑到第二頁。

3逐字／語氣說明

保存詞義、文法、語感、容易誤譯的句子或你從 AI 貼回的解說。

AI 上下文精修／設定 API有 Key 時讀取你設定的前文、後文與引用訊息後重譯；沒有 Key 時會帶你到 API 分頁。
複製複製目前的完整譯文或語氣說明。
完成儲存目前欄位；若在「整理」或「串聯」，也會建立對應項目與上下文快照。
取消關閉視窗，不套用尚未完成的整理或串聯動作。

每個分頁能做什麼

先看標題，需要細節時再展開。所有文字都能跟著介面語言切換成繁體中文或韓文。

翻譯免 Key 初譯、語言方向與翻譯對象
  • 預設用免填 API Key 的 Google 初譯，自動處理目前與之後載入的訊息。
  • 來源語言可複選 한국어、繁體中文、English；譯文可選繁體中文或 한국어，系統會禁止自己翻譯自己。
  • 可選雙方、只翻譯對方或只翻譯自己；關閉「自動顯示翻譯」只會隱藏翻譯，不會刪除資料。
訊息編輯：翻譯、語氣、整理、串聯更正譯文、摘錄片段、建立標籤與問題串
  • 「翻譯」與「語氣說明」可直接貼入、修改並保存你認為較準確的內容。
  • 「整理」可切換待做或筆記，保存完整訊息或只保存反白片段，同時保留原文與譯文。
  • 「串聯」可建立／加入訊息分支並加上 #標籤；之後能從搜尋／備份分頁查看整串訊息。
待做推薦項目、待回答問題與稍後行動
  • 每張卡片可顯示標題、譯文摘錄與原文摘錄；點卡片可看詳情、編輯、複製或嘗試在 X 中定位。
  • 「複製整理」一次複製整份待做清單，方便貼到其他平台；× 只會從待做移除，不會刪除 X 訊息。
筆記人物偏好、關係資訊與任何自由記錄
  • 可從訊息建立筆記，也可在筆記分頁直接輸入一行新增，不必綁定任何訊息。
  • 從訊息建立的筆記會保存原文、譯文、當時前後文與引用快照；可開啟詳情編輯。
  • 「複製整理」可一次複製全部筆記；× 只從筆記清單移除。
單字本單字、意思、發音與主題分類
  • 新增時填寫單字與意思；發音和主題可選填。至少需要單字與意思。
  • 單字會依主題收進可摺疊清單；點單字即可編輯，× 可刪除。
  • 「複製整理」會依主題輸出整份單字本。
搜尋／備份跨原文與譯文搜尋、日曆、Markdown、Notion
  • 搜尋範圍包含原文、所有方向的譯文、語氣說明、待做、筆記、單字、標籤、分支與對話名稱。
  • 展開「對話日曆」並按「掃描舊對話」，工具會自動往回捲動，記住每天第一則訊息，完成後回到最新訊息；只需做一次，新日期之後會自動加入。
  • 有多個對話的資料時才顯示「目前對話／全部對話」切換。點結果可查看已快取詳情，即使 X 當下找不到原訊息。
  • 可複製或下載 Obsidian Markdown，也可下載／匯入 JSON 備份包。
  • Notion 同步需填 Cloudflare 同步閘道網址與同步密碼；支援首次完整備份、後續增量同步、從 Notion 讀回與衝突預覽。
API選用 Gemini 或 OpenAI 相容服務進行上下文精修
  • API 完全選用；不填 Key 仍可使用 Google 初譯、手動編輯與所有整理功能。
  • OpenAI 相容模式預填官方 Base URL 與原本模型；一般 OpenAI 使用者不必更改，也能自行填入其他相容服務的 Base URL 與模型名稱。
  • 可設定帶入 0–3 則前文、0–3 則後文，以及是否包含引用訊息。Key 預設只保留到頁面關閉；主動勾選「記住在此網站」才會保存在這台裝置。

資料保存與被刪除的訊息

工具不會假裝知道 X 沒有提供的狀態；能保存的內容與限制會明確標示。

本機快取

譯文、語氣、待做、筆記、單字、標籤、分支與上下文快照會保存在目前瀏覽器的 x.com localStorage。Clean 不會刪除這些資料。

引用中的已刪除內容

只要 X 的灰色引用框仍顯示文字，工具就會保存該段內容及引用關係。原訊息消失可能是被刪除，也可能只是尚未載入，因此未經證據只標示「無法確認」。

跨裝置

不同裝置的本機快取彼此獨立。可使用 JSON 備份包手動搬移，或設定 Notion 同步閘道，在新裝置先預覽差異再合併。

安全提醒

同步密碼不是 Notion Token。不要把 Notion Token、同步密碼或 API Key 貼到 GitHub。只在自己的裝置選擇「記住」。
