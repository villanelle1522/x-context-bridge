X Context Bridge

免費安裝到電腦、Android 與 iPhone。安裝一次，以後開啟 X 網頁版私訊就會自動執行。

書籤短版已停止推薦。 實測確認 X 會以強制 CSP 阻擋從 GitHub Pages 載入外部程式；離線完整版又超過許多手機的書籤長度。Userscript 是目前可靠且免費的方式。

電腦

Chrome、Edge 或 Firefox 先安裝免費的 Violentmonkey，再安裝 X Context Bridge。

  1. 安裝 Violentmonkey
  2. 回到本頁安裝腳本
安裝 X Context Bridge

Android

手機 Chrome 不支援擴充功能。請使用 Firefox Android 與免費 Violentmonkey。

  1. 在 Firefox 安裝 Violentmonkey
  2. 用同一個 Firefox 回到本頁
安裝 X Context Bridge

iPhone／iPad

安裝免費 Userscripts，並在 Safari 延伸功能中允許它存取 x.com。

  1. 從 App Store 安裝 Userscripts
  2. 用 Safari 回到本頁並開啟 Userscripts
開啟安裝檔

主控台完整版

開發與快速測試使用。複製後，到 x.com/messages 的主控台貼上整份程式。

無法自動複製時，開啟完整程式檔

測試介面移除指令：window.__xcbConsoleCleanup?.()。已儲存的譯文、待做、筆記與單字本仍會保留。

使用限制

工具只能修改 X 網頁版，不能覆蓋 Android 或 iPhone 的原生 X App。不同裝置的本機快取各自保存；設定 Notion 同步閘道後，可在新裝置先預覽再讀回。
