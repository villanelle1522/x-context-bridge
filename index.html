X Context Bridge

手機推薦：Userscript

如果短版書籤跳出「載入失敗」，或離線書籤太長無法儲存，請改安裝 X_CONTEXT_BRIDGE.user.js。這是給腳本管理器使用的版本，不需要把長程式塞進書籤網址。

最簡單的安裝方式

電腦可直接把上面的藍色按鈕拖到書籤列。手機請不要只複製 GitHub 網址，要把 GITHUB_BOOKMARKLET.txt 裡面整串 javascript: 內容貼到書籤網址。

如果在 X 上沒有反應

先用 書籤自我測試 確認瀏覽器有沒有執行 javascript:。若測試會跳出提示，但短版沒有反應，表示 X 擋住外部載入；請改用 直接版離線書籤。

三種書籤版本

短版 最好更新，但可能被 X 擋外部載入。直接版 不連 GitHub、不用 eval，比較適合 X 擋載入時。Base64 離線版 比直接版更容易被 eval 限制影響。

  1. 手機先把任意頁面加入書籤。
  2. 編輯剛才的書籤，名稱改成 X Context Bridge。
  3. 把網址替換成 GITHUB_BOOKMARKLET.txt 的完整內容，不是檔案網址。
  4. 開啟 X 私訊網頁後執行這個書籤。

離線書籤很長；有些手機瀏覽器會限制書籤網址長度。遇到長度限制時，Userscript 是比較穩的手機方案。
